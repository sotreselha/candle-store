Candle store + replay — stub series, fee.

## Features

- Venue binance / ETHUSDT
- Strategy ema
- Paper backtest, no live orders

## Prerequisites

- Rust 1.75+
- Git

## Getting Started

```bash
git clone <repo-url>
cd candle-store
cargo build --release
./target/release/candle-store --help
```

## Tests

```bash
cargo test
```
